# BNT Gambia Evidence MCP

MCP server for accessing and querying BNT's Gambia evidence sources.

## Purpose

This connector will allow an AI assistant such as Claude to access structured evidence and research sources relevant to The Gambia.

## Current sources

- Data Warehouse Pro — Central Bank of The Gambia
- Gambia Bureau of Statistics
- Government of The Gambia
- Facebook/public information sources
